# Grădiniță

# Descriere
Proiect realizat în C++ pentru gestionarea copiilor și grupelor dintr-o grădiniță.

# Funcționalități
- Afișarea copiilor și grupelor.
- Adăugarea unui copil.
- Adăugarea unei grupe.
- Ștergerea unui copil.
- Ștergerea unei grupe.

# Fișiere
- main.cpp – meniul principal.
- afisari.h – afișarea informațiilor.
- nou.h – adăugarea datelor.
- stergerea.h – ștergerea datelor.
- Child.txt – informații despre copii.
- Group.txt – informații despre grupe.

# Limbaj
C++
